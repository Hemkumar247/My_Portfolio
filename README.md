# Hem Kumar Portfolio

Personal portfolio website built with Next.js, TypeScript, GSAP, Framer Motion, and Three.js.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
npm run start
```

## Deploy on Vercel

This project is ready to deploy directly on Vercel as a standard Next.js app.

1. Push this repository to GitHub.
2. Import the repository into Vercel.
3. Keep the framework preset as `Next.js`.
4. Keep the root directory as the repository root.
5. Use the default commands:
   `npm install`
   `npm run build`
6. Deploy.

No extra environment variables are required for the current version of the site.
